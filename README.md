## 功能模式

| 模式 | 状态 | 说明 |
|------|------|------|
| 主线模式 | ✅ 可玩 | 第一章垂直切片已接入（占位剧本） |
| 角色剧情 | 🚧 框架就绪 | 角色列表已建，首位角色「仕衣」待接入剧情 |
| 干员档案 | 🚧 占位 | 立绘一览 / 档案文本 / 语音试听 |
| 故事集 | 🚧 占位 | 活动故事 / 短篇集 / 世界观补充阅读 |
| 时间线 | 🚧 占位 | 泰拉纪年 / 大事件年表 / 剧情节点回溯 |

## 系统功能

- **对话演出**：深色半透明对话框（顶部琥珀发丝线）、左侧强调色姓名条、打字机效果、点击继续指示器（琥珀三角呼吸动画）
- **快捷工具栏**：游戏中常驻右上角（不遮挡对话框/立绘文字）——回退 / 隐藏 / 自动 / 快进 / 存档 / 读档 / 历史 / 设置 / 标题
- **存读档**：6 格手动存档 + 自动存档页，带缩略图与时间戳
- **设置**：文字速度、自动前进间隔、音乐 / 音效 / 语音音量（琥珀滑条）、窗口全屏切换、跳过未读文本
- **历史记录**：可回看全部已读对话
- **Esc / 鼠标右键**：直接打开保存界面（左侧导航可切到读档/设置/历史，当前项琥珀高亮）

## 视觉风格

- 自绘 UI 素材（`game/gui_gen/`，共 19 张），不依赖官方美术资源
- 背景：垂直渐变 + 45° 细网格 + 噪点 + 水平发丝线 + 四角科技括号 + 暗角
- 琥珀色（#E3B457）作为强调色，冷灰蓝（#7FB3D5）作为信息色
- 模式选择为 3×2 卡片网格（左琥珀条 + 角标序号 + hover 琥珀描边）
- 标题/栏目统一使用「渐隐线 + 中央菱形」装饰线（deco_line）
- 所有按钮/面板/姓名条均使用 9 宫格（9-patch）缩放；素材原生 96/128px，高 DPI 下依然锐利

## 本地运行

1. 安装 [Ren'Py 8.5.3+ SDK](https://www.renpy.org/download.html)
2. 双击 `run.bat`（默认读取 `F:\bian\renpy\renpy-8.5.3-sdk`，SDK 在别处请设环境变量 `RENPY_SDK`）
3. 或命令行直启：

```bash
<renpy-sdk>/lib/py3-windows-x86_64/renpy.exe <本项目路径>
```

**脚本校验**：双击 `lint.bat`，或命令行 `renpy.exe <本项目路径> lint`

## 项目结构

```
arknights-avg/
├── game/
│   ├── options.rpy        # 引擎配置：画面、存档、缩略图、全局字体、Esc 行为
│   ├── characters.rpy     # 角色定义、全局状态变量
│   ├── script.rpy         # 主流程：标题 → 模式选择 → 各模式入口 → 主线章节
│   ├── chara_story.rpy    # 角色剧情模块（每角色一条线）
│   ├── screens.rpy        # 导航层：标题、模式选择、角色列表、确认弹窗、结束卡
│   ├── ui_extra.rpy       # 演出层：对话框、姓名条、选项按钮、快捷工具栏
│   ├── menu_screens.rpy   # 菜单层：游戏菜单、存读档、设置、历史记录
│   ├── gui_gen/           # 自绘 UI 素材（背景、面板、按钮、姓名条等）
│   └── fonts/msyh.ttc     # 中文字体（微软雅黑）
├── tools/
│   ├── gen_ui.py          # UI 素材生成器；修改风格后可重新生成
│   └── check_assets.py    # 素材完整性/尺寸自检脚本
├── run.bat / lint.bat     # 一键启动 / 校验脚本
└── README.md
```

## 开发约定

- **新增主线章节**：在 `script.rpy` 加 `label ch<N>_<名称>`，从 `chapter_select` 挂载
- **新增角色剧情**：`screens.rpy` 的 `chara_story_list` 加按钮 + `chara_story.rpy` 加 `ch_<角色拼音>_01` 标签
- **新增角色定义**：`characters.rpy` 加 `define`，统一带 `ctc="ctc_arrow"`
- **文本结束**：统一用 `call end_card("...")` 收尾并回到导航
- **改 UI 风格**：编辑 `tools/gen_ui.py` 调色板，运行 `python tools/gen_ui.py` 重新生成 `gui_gen/`
- **提交前**：跑 `lint.bat` 确保无错误
